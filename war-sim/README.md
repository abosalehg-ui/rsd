# 🎯 محاكاة حرب إيران 2026 — War Simulation

### تحليل ذكي وسيناريوهات ديناميكية لنهاية الحرب

جزء من مشروع [رصد (Rsd)](https://github.com/abosalehg-ui/rsd)

---

## 📋 نظرة عامة

محاكاة تحليلية تفاعلية تستخدم **Claude AI** مع **بحث الويب الفوري** لتحليل آخر تطورات حرب إيران 2026 وتوليد سيناريوهات نهاية الحرب المتوقعة **يومياً** بناءً على المعطيات الحقيقية.

### ما يميز هذه المحاكاة:

| الميزة | الوصف |
|--------|-------|
| 🤖 **تحليل AI فوري** | Claude يبحث في الويب ويحلل آخر الأحداث |
| 🔄 **سيناريوهات ديناميكية** | تتغير يومياً حسب المعطيات — ليست ثابتة |
| 📊 **بيانات عسكرية** | صواريخ، منصات، نووي، دفاعات، بحرية |
| 🛢️ **توقعات اقتصادية** | أسعار نفط، مضيق هرمز |
| ⏱️ **محاكاة زمنية** | شغّل المحاكاة وشاهد تطور كل سيناريو |
| 📱 **متوافق مع الجوال** | تصميم mobile-first |

## 🔑 مفتاح API

المحاكاة تستخدم **Anthropic Claude API** للتحليل الفوري.

- المفتاح يُحفظ في `localStorage` بعد أول إدخال
- لا يُرسل لأي جهة غير Anthropic
- تقدر تقطع الاتصال وتحذف المفتاح من الشريط العلوي

**بدون مفتاح:** المحاكاة تعمل ببيانات افتراضية وسيناريوهات ثابتة.
