### 2.4 معالجة الأخطاء والحالات الحدّية — **7.5/10**

**(أ) 🟠 ملف `.env` في جذر المستودع لا يُقرأ في مسارَي التشغيل الأساسيين.** README (قسم التشغيل وقسم «المتغيّرات البيئية») يقول: `cp .env.example .env` في الجذر، و«أنشئ ملف `.env` في المجلد الرئيسي». لكن:

- `Rasad.bat` ينفّذ `cd /d "%~dp0backend"` ثم `run_desktop.py`.
- الطريقة C في README: `cd backend && uvicorn app.main:app`.

وفي الحالتين `cwd = backend/`، و`config.py::_env_files()` تعيد `".env"` نسبيًا. **أعدتُ إنتاجه**: وضعتُ `NEWSAPI_KEY=rootkey123` في `rsd/.env` وشغّلتُ `Settings()` من `backend/` → `newsapi_key == ''`؛ ومن الجذر → `'rootkey123'`. فمستخدم `Rasad.bat` (قناة التوزيع الأولى في README) يضع مفاتيح NewsAPI وFRED وUCDP حيث قيل له فتُتجاهل بصمت، ويرى «NewsAPI: لا مفتاح» و«أضف FRED_API_KEY» رغم أنه أضافه. Docker وحده يعمل لأن compose يحقن الملف كمتغيّرات بيئة.

**الحل** في `config.py`:

```python
_REPO_ROOT = Path(__file__).resolve().parents[2]

def _env_files():
    files = [str(_REPO_ROOT / ".env"), ".env"]   # الجذر ثم مجلد التشغيل (الأخير يغلب)
    if getattr(sys, "frozen", False):
        files.append(str(get_app_data_dir() / ".env"))
    return tuple(files)
```

مع اختبار في `test_main.py`/`test_hardening.py` يكتب `.env` مؤقتًا في جذر وهمي ويتأكد أن `Settings()` تقرأه من مجلد فرعي. وحتى يُنفَّذ: سطر في README «الملف يُقرأ من `backend/.env`».

**(ب) 🟠 صفحة `/docs` (Swagger) معطّلة في كل نشر يصل الخلفية مباشرة.** README يروّج `API Docs: http://localhost:8000/docs`. لكن `middleware/security_headers.py::SecurityHeadersMiddleware` تُلبس كل مسار غير `/api/*` سياسة `script-src 'self'`، و`/docs` التي يولّدها FastAPI تحمّل `https://cdn.jsdelivr.net/npm/swagger-ui-dist@5/swagger-ui-bundle.js` **وسكربتًا مضمّنًا** يبدأ `SwaggerUIBundle(...)`. **أعدتُ إنتاجه** بطلب ASGI: `/docs` و`/openapi.json` يردّان بترويسة CSP الكاملة، والصفحة تحوي `src="https://cdn.jsdelivr.net/…"` و`<script>` مضمّنًا — المتصفح يحجب الاثنين فتفتح صفحة بيضاء. ينطبق على Docker dev (المنفذ 8000 مكشوف محليًا) وعلى سطح المكتب والطريقة C. (`/redoc` كذلك.)

**الحل** في `security_headers.py`:

```python
_DOCS_PREFIXES = ("/docs", "/redoc", "/openapi.json")
DOCS_CSP = (
    "default-src 'self'; img-src 'self' data: https://fastapi.tiangolo.com; "
    "script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; "
    "style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; frame-ancestors 'none'"
)
...
if request.url.path.startswith(_DOCS_PREFIXES):
    headers = {**SECURITY_HEADERS, "Content-Security-Policy": DOCS_CSP}
```

أو — الأبسط والأشدّ — `docs_url=None, redoc_url=None` عند `sys.frozen` (المستخدم النهائي لا يحتاج Swagger) مع إبقائها في التطوير بسياسة الوثائق. واختبار: `GET /docs` → 200 وترويسة CSP تسمح بـ`cdn.jsdelivr.net`.

**(ج) 🟡 مجموعة UCDP الافتراضية لا تُنتج أحداثًا حديثة.** `config.py`: `ucdp_dataset: str = "24.1"`، و`.env.example` نفسه يحذّر: «المجموعات السنوية (مثل 24.1) تنتهي عند نهاية سنتها، فلا تُنتج أحداثًا حديثة؛ استخدم مجموعة المرشّحين الشهرية». أي أن الافتراضي **هو** ما يحذّر منه القالب. مستخدم يضع رمز UCDP ويترك الباقي يحصل على مصدر «مفعّل» يعود دومًا بصفر حدث (الجامع يرشّح ما قبل `since` = 30 يومًا) ويظهر `healthy: false` في `/collectors/status` بلا تفسير. **الحل:** اجعل الافتراضي مجموعة المرشّحين (`candidateevents/<الإصدار الشهري الحالي>` وفق توثيق UCDP) أو، إن لم يكن ثابتًا، أفرغ الافتراضي واجعل الجامع يسجّل تحذيرًا صريحًا «UCDP_DATASET غير مضبوط» ويعلن `disabled` في `/sources`.

**(د) 🟡 ترقيم الصفحات في `GET /api/events/` غير متّسق مع الطيّ.** `api/events.py::get_events`:

```python
fetch = min(limit * 3, 1500) if collapse_stories else limit
query = query.order_by(desc(Event.event_date)).offset(offset).limit(fetch)
...
items = collapse(events, limit) if collapse_stories else [...]
```

`offset` يُطبَّق على **الصفوف الخام** و`limit` على **القصص**، فالصفحة الثانية (`offset=limit`) تتخطّى `limit` صفًا خامًا لا `limit` قصة: قصص تتكرّر بين الصفحتين أو تضيع. الواجهة لا تستعمل `offset` اليوم، لكن المسار عام وموثّق. **الحل:** إمّا إزالة `offset` عند `collapse=true` (422 إن أُرسل) أو ترقيم بمؤشّر زمني (`before=<event_date>`) وهو الأنسب لخلاصة تتغيّر باستمرار.

**(هـ) 🟡 زر «تحديث» لا يحدّث التبويب الافتراضي.** `App.jsx::handleRefresh`:

```js
refetchEvents();
```

### 2.5 الأداء واستهلاك الموارد — **8.0/10**

**الإيجابيات:** `NuclearRow`/`ImpactRow` الخفيفة، و`ROW_NUMBER` في `load_impact_rows`، والفهارس المركّبة، وتزامن الخلاصات بـSemaphore، و`feedparser` خارج حلقة الأحداث، والـ`asyncio.Lock` حول الجمع البارد للطيران — كلها موجودة ومختبَرة.

**(أ) 🟡 `app/cache.py::cached` بلا قفل لكل مفتاح.** قستُه: خمسة طلبات متزامنة للمفتاح نفسه → **خمس** عمليات حساب. مع ثلاثة تبويبات تستطلع `/nuclear/risk` و`/impact/ksa` و`/markets/correlation` في الدقيقة نفسها تتكرّر أثقل الحسابات بعدد التبويبات في لحظة انتهاء الصلاحية. **الحل:**

```python
_locks: dict[Hashable, asyncio.Lock] = {}

async def cached(key, ttl, compute):
    ...
    lock = _locks.setdefault(key, asyncio.Lock())
    async with lock:
        hit = _store.get(key)                 # فحص ثانٍ بعد القفل
        if hit is not None and hit[0] > now: return hit[1]
        value = await compute()
```

**(ب)** 2.3-ب و2.3-ج أعلاه (تسلسل مزدوج في التقرير، وإثراء المنشآت في كل طلب).

**(ج)** لا يمكن الحكم على الأداء الفعلي (زمن `/nuclear/brief` على قاعدة سطح مكتب عمرها شهر) من الكود وحده؛ الأرقام في المراجعة السابقة (0.6 ثانية للتزامن على 60 ألف حدث) تبقى المرجع.

### 2.7 التوثيق — **8.0/10**
