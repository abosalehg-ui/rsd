## 1. نظرة عامة سريعة

**وش يسوي:** رصد لوحة شخصية تجمع أخبار وأحداث الشرق الأوسط العسكرية/الأمنية من 6 مصادر (GDELT، NewsAPI، RSS، UCDP، ADS-B، خلاصات OSINT إيرانية)، تصنّفها بالكلمات المفتاحية، تحدّد موقعها الجغرافي تقريبيًا، وتعرضها على خريطة 2D (Leaflet) أو كرة 3D (globe.gl) مع تنبيهات صوتية وواجهة ثنائية اللغة RTL/LTR.

**البنية:** باك إند FastAPI بطبقات واضحة (`collectors → processors → models → api + middleware`) على SQLite غير متزامن مع مجدول APScheduler، وواجهة React أحادية الصفحة تستطلع الـ API دوريًا. ثلاث طرق نشر: Docker (dev/prod)، GitHub Pages للواجهة، ومثبّت ويندوز (PyInstaller + Inno Setup). مجلد Tauri موجود لكنه غير مكتمل (انظر 2.7).

### 2.3 التكرار (DRY) و Code Smells — **7.0/10**

إزالة التكرار السابقة (`_feed_base`، `dates`، `text_analysis`، `_serializers`) نُفّذت فعلاً وواضحة. المتبقي:

**(أ) سياسة CSP مكتوبة 5 مرات بنصّها الكامل:** `index.html` (meta)، `nginx.conf` ثلاث مرات (server + `/assets/` + `/sw.js`)، و`tauri.conf.json`. أي تعديل مصدر واحد (مثل إضافة CDN) يحتاج 5 تعديلات متطابقة. **الحل:** في nginx ضع الترويسات في `security-headers.conf` واستخدم `include` داخل كل `location`؛ ولّد meta الـ HTML من نفس الملف في خطوة بناء صغيرة.

**(ب) `Header.jsx` يستخدم `setTimeout(…, 0)` للالتفاف على قاعدة React:**

```jsx
useEffect(() => {
  if (!stats) return undefined;
  const id = setTimeout(() => setLastFetch(new Date()), 0);
  return () => clearTimeout(id);
}, [stats]);
```

المطلوب فعليًا "وقت آخر استجابة" وهو معلومة يملكها `usePolling`. **الحل:** أعد `lastFetchedAt` من `usePolling` ومرّره للهيدر بدل اشتقاقه من تغيّر هوية `stats`.

**(ج) `news_api.py` يحسب البصمة بنفسه** `hashlib.md5(url.encode()).hexdigest()` بينما `_feed_base.make_source_id()` موجود لهذا الغرض (ومعه `usedforsecurity=False` لأنظمة FIPS). **الحل:** `make_source_id("newsapi", url)`.

**(د) `frontend/src-tauri/` مسار ميت:** `tauri.conf.json` يشير إلى `icons/32x32.png` و`icons/icon.ico` والمجلد `src-tauri/icons/` غير موجود أصلًا، و`README.md` لا يذكر Tauri كطريقة نشر (المثبّت عبر PyInstaller). أمر `npm run tauri:build` يفشل من أول خطوة. **الحل:** احذف المجلد وسكربتات `tauri*` من `package.json`، أو أكمله وأضفه لـ CI.

### 2.4 معالجة الأخطاء والحالات الحدّية — **6.5/10**

المهلات صريحة في كل `httpx.AsyncClient`، الجامعون يرفعون استثناءً عند فشل *كل* الخلاصات (لا 0 صامت)، و`insert_event_if_new` ذرّي بـ `ON CONFLICT DO NOTHING`. ثلاث مشاكل جوهرية:

**(أ) 🔴 جامع UCDP لا يمكن أن يُنتج حدثًا يظهر في الواجهة.** `collectors/ucdp.py::collect_ucdp_events`:

```python
UCDP_API = "https://ucdpapi.pcr.uu.se/api/gedevents/24.1"
params = {"pagesize": 100, "page": 0}
response = await client.get(UCDP_API, params=params)
```

`gedevents/24.1` مجموعة البيانات **السنوية** (GED v24.1 تغطي حتى نهاية 2023)، والطلب بلا فلتر دولة ولا تاريخ فيجلب أول 100 صف من المجموعة العالمية كاملة. كل ما يُخزَّن له `event_date` أقدم بسنوات من أقصى نافذة عرض في الواجهة (`hours ≤ 720`)، فالمصدر يُدرج صفوفًا لا تظهر أبدًا، ثم يُحذف بعد 30 يومًا ويعيد الكرّة. `/api/collectors/status` يُظهره "صحيًا" لأنه جمع شيئًا. **الحل:** استخدم نقطة التحديثات الشهرية (`gedevents/<year>.0.<month>` — "GED Candidate") مع `Country=` و`StartDate=` (يدعمهما الـ API)، أو احذف المصدر بدل الإيحاء بأنه يعمل. أضف اختبارًا يُحاكي الاستجابة ويتأكد أن الحدث المُدرَج يقع داخل النافذة.

**(ب) 🟠 `collectors/adsb.py::collect_flights` يمسح آخر لقطة صالحة عند أي فشل عابر:**

```python
except Exception as e:
    logger.error(f"خطأ في جمع بيانات الطيران: {e}")

# حدّث اللقطة المشتركة (تقرأها /flights/live)
_last_snapshot.update(total=flights_data["total"], military=..., flights=flights_data["flights"], ...)
```

`flights_data` هنا فارغ `{"total":0, "flights":[]}`، فانقطاع شبكة لثانية أو 429 من adsb.lol يجعل الخريطة تعرض "0 رحلة" بدل الإبقاء على لقطة عمرها 30 ثانية. **الحل:** حدّث `_last_snapshot` داخل مسار النجاح فقط، وأضف `stale: true` + `updated_at` القديم عند الفشل ليُظهر الـ UI "بيانات قديمة".

**(ج) 🟠 NewsAPI يستنزف حصته المجانية خلال ساعة.** `news_api.py::collect_news` يُرسل 6 استعلامات × لغتين = **12 طلبًا كل 10 دقائق = 1,728/يوم** مقابل حد المستوى المجاني 100/يوم. الجامع يرفع `RuntimeError` عند 429 (وهذا صحيح) لكن النتيجة أن المصدر يعمل ~50 دقيقة يوميًا ثم يُعلَّم "معطّل". **الحل:** استعلام واحد مركّب بـ `OR` لكل لغة (طلبان/دورة)، ورفع `newsapi_interval` الافتراضي إلى 3600 ثانية؛ أو اقرأ ترويسة `X-RateLimit-Remaining` وتوقف مبكرًا.

**(د) 🟡 `/api/refresh` يعتمد على متغيّر عملية واحدة** (`_last_manual_refresh` global). صحيح لتطبيق سطح المكتب، لكن مع `uvicorn --workers 2` يصير لكل عامل عدّاده. يكفي توثيقه في التعليق (كما فُعل في `ratelimit.py`).
